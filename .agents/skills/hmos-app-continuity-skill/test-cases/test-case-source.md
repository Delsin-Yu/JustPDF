# tc_006：源端保留不退出

## 基本信息

- **编号**：tc_006
- **标题**：源端保留不退出
- **文件名**：test-case-source

## 用户指令

> 我的备忘录项目希望在手机上写了半篇文档，能接续到平板上写。但手机上的应用不要关，等我确认平板接收完了、数据都对了，再手动关手机这边。帮我实现这个功能。


## 重点验证标准

| ID | 标准 | 典型失败行为 |
|---|--------|---------------------------|
| S11 | 源端若接续后保留进度，不对源端内容做多余处理 | 忽略源端退出设置、默认退出（该保留没保留）；源端保留运行时仍做额外数据清理/状态重置，破坏源端进度与草稿 |
| S12 | 完成报告字段齐全 | 只说"做完了"或只列改动清单，缺修改摘要、引导确认摘要、验证结果、人工清单等字段 |
| S13 | 环境能编译则要求编译通过；不能编译则在报告写明，不谎称已通过 | 使用不存在的方法/类型/导入导致编译 ERROR；环境不能编译时谎称"编译已通过" |

# tc_005：页面栈迁移

## 基本信息

- **编号**：tc_005
- **标题**：页面栈迁移
- **文件名**：test-case-navigation

## 用户指令

> 添加应用接续功能，注意用户从首页 → 分类 → 商品详情 → 下单确认，在这个路径上触发了接续，目标端要停在"下单确认"页面，按返回键依次回到商品详情 → 分类 → 首页。


## 重点验证标准

| ID | 标准 | 典型失败行为 |
|---|--------|---------------------------|
| S10 | 不修改原工程路由方式，只在原有路由方式上按需进行页面栈迁移 | 未向用户确认就把 `Navigation` 改成 `Router` 来"简化接续实现"；`Router` 栈恢复接线错误——未在 `onCreate/onNewWant` 执行完成前同步调用 `restoreWindowStage()` 致迁移后白屏，或无条件在 `onWindowStageRestore` 中 `loadContent` 摧毁系统已恢复的栈 |
| S12 | 完成报告字段齐全 | 只说"做完了"或只列改动清单，缺修改摘要、引导确认摘要、验证结果、人工清单等字段 |
| S13 | 环境能编译则要求编译通过；不能编译则在报告写明，不谎称已通过 | 使用不存在的方法/类型/导入导致编译 ERROR；环境不能编译时谎称"编译已通过" |
